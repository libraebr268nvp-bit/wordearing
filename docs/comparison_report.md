# WordWiz 功能对比分析报告

> 对比 WordWiz 与主流单词学习 App 及 GitHub 开源项目，提出可添加功能建议

---

## 一、WordWiz 现有功能全景

### 1.1 学习浏览
| 功能 | 说明 |
|------|------|
| 词书筛选 | 多选式激活/停用词书（多归属 book_ids） |
| 分类筛选 | 动态从数据库提取分类（四级/六级/考研等） |
| 模糊搜索 | 300ms 防抖，匹配单词和中文释义 |
| 6 种排序模式 | 默认/熟悉度↑↓/字母A-Z Z-A/随机混序 |
| 单元展开/折叠 | 按单元分组，可折叠 |
| 全局混序 | 跨单元打乱单词顺序 |

### 1.2 单词操作
| 功能 | 说明 |
|------|------|
| 熟悉度系统 | 0~5 级，点击 ✓ 递增（间隔复习联动） |
| 收藏/取消收藏 | ⭐ 按钮即时切换 |
| 软删除 → 回收站 | ✕ 按钮移入，30 天自动清理 |

### 1.3 挑战模式
| 功能 | 说明 |
|------|------|
| 3 种题型 | 四选一 / 汉→英拼写 / 英→汉拼写 |
| 难度筛选 | 简单(熟悉度≥3) / 普通 / 困难(熟悉度≤2) |
| 生命值模式 | 3 条命 |
| 限时模式 | 每题 10 秒 |
| 错题自动收集 | 写入 challenge_wrong_words |
| 7 天冷却 | 已挑战单词不重复出题 |
| 间隔复习联动 | due_date 到期单词专项复习 |

### 1.4 数据管理
| 功能 | 说明 |
|------|------|
| 导入 | CSV/JSON 导入，自动创建词书 |
| 导出 | JSON/CSV 导出（含熟悉度/收藏状态） |
| 词书管理 | 新增/删除/名称修改 |
| 错题集查看/清空 | 分类筛选 + 导出 + 清空 |
| 回收站管理 | 查看/恢复/永久删除/自动清理 |

### 1.5 统计与成就
| 功能 | 说明 |
|------|------|
| 统计仪表盘 | 总数/已学/收藏数 |
| 7 天学习趋势折线图 | Chart.js |
| 学习热力图 | 自实现 GitHub 风格日历 |
| 成就系统 | 10 个成就（初次挑战/满分王/速度之星/连对达人等） |
| 挑战历史 | 最近 20 条记录 |

### 1.6 其他
| 功能 | 说明 |
|------|------|
| 每日复习提醒 | 桌面通知 + Toast + 提示音，可设时间 |
| 局域网访问 | WebRTC 获取 IP 地址 |
| 深色科技感主题 | 网格点阵背景，霓虹色系 |
| 移动端适配 | 响应式 + 汉堡菜单 |
| 无框架零依赖 | 纯 HTML+CSS+JS，IndexedDB 本地存储 |

## 二、与主流 App 功能对比

### 2.1 百词斩

百词斩以**图片记忆**为最大特色 —— 每个单词配一张趣味图片和多个例句场景。

| 维度 | 百词斩 | WordWiz | 差异 |
|------|--------|---------|------|
| **单词展示** | 图片 + 单词 + 例句 + 词根拆解 | 单词 + 中文释义 | ❌ 缺少图片/例句/词根 |
| **学习模式** | 图片选择 / 听音选义 / 拼写 / 填空 | 四选一 / 汉→英拼写 / 英→汉 | ✅ 基础题型齐全 |
| **复习机制** | 艾宾浩斯曲线 + 专项复习（听写/快速刷词） | 间隔复习（due_date）+ 挑战模式复习 | ⚠️ 间隔复习已有但算法简单 |
| **内容丰富度** | 词根词缀、象形记忆、TV 剧场景 | 仅单词+释义 | ❌ 缺乏辅助记忆内容 |
| **UI 风格** | 清新插画风，色彩活泼 | 深色科技风，网格点阵 | 风格差异，各有所长 |
| **社交/打卡** | 同桌系统、学习圈、打卡排名 | ❌ 无 | ❌ 缺失 |
| **听力学** | 单词朗读、例句跟读、听力训练 | ❌ 无发音 | ❌ 缺失 |

### 2.2 墨墨背单词

墨墨背单词以**科学的间隔重复算法**和**丰富的记忆辅助**著称。

| 维度 | 墨墨背单词 | WordWiz | 差异 |
|------|----------|---------|------|
| **间隔复习算法** | 基于艾宾浩斯 + 用户反馈数据的 SM-2 变体 | 简单线性间隔（1/2/4/7/15/30天） | ❌ 算法不够精细 |
| **记忆辅助** | 助记方法（用户共创）、词根词缀、谐音 | ❌ 无 | ❌ 缺失 |
| **词库量** | 海量词库（考研/雅思/托福/GRE + 用户上传） | 8 本内置词库（CET4/6/考研/托福/雅思/GRE/高考/中考） | ⚠️ 已有基础词库但无社区词库 |
| **学习统计** | 详细的学习历史、遗忘曲线、复习预测 | 基础统计 + 热力图 + 7 天趋势 | ⚠️ 有一定统计但缺少遗忘曲线预测 |
| **UI 风格** | 极简卡片风，信息密度高 | 按单元分组展示 | 风格不同 |
| **自定义** | 自定义学习计划（每日新词数） | ❌ 无学习计划 | ❌ 缺失 |

### 2.3 不背单词

不背单词以**真实语境（影视原声例句）**为核心特色。

| 维度 | 不背单词 | WordWiz | 差异 |
|------|---------|---------|------|
| **语境学习** | 每个单词配 4-6 个影视/新闻原声例句 | ❌ 无例句 | ❌ 缺失 |
| **听音学** | 原声发音 + 跟读评分 | ❌ 无发音 | ❌ 缺失 |
| **沉浸式 UI** | 全屏沉浸，每词一页 | 列表式展示 | 风格不同 |
| **随身听模式** | 锁屏听单词、磨耳朵 | ❌ 无 | ❌ 缺失 |
| **词组搭配** | 展示高频搭配、短语 | ❌ 无 | ❌ 缺失 |
| **派生/同反义词** | 派生词、同义词、反义词 | ❌ 无 | ❌ 缺失 |

### 2.4 Quizlet

Quizlet 是全球最大的单词学习平台，以**灵活的学习模式**和**社区词集共享**著称。

| 维度 | Quizlet | WordWiz | 差异 |
|------|--------|---------|------|
| **学习模式多样性** | 闪卡 / 学习 / 测试 / 配对游戏 / 重力模式 | 四选一 / 拼写模式 | ❌ 缺少游戏化模式 |
| **社区词集** | 数亿用户创建的词集，按主题分类 | ❌ 仅有内置词库 | ❌ 缺失社区功能 |
| **AI 功能** | Quizlet Q-Chat（AI 辅导）、AI 出题 | ❌ 无 | ❌ 缺失 |
| **多人协作** | 班级/小组共享词集，课堂模式 | ❌ 无 | ❌ 缺失 |
| **多语种** | 100+ 语言支持 | 仅中英 | ❌ 缺少多语言 |
| **富媒体** | 图片、音频上传自定义 | ❌ 无 | ❌ 缺失 |
| **离线学习** | 移动端离线访问 | ✅ PWA 形式本地存储 | ✅ 本质就是离线的 |
| **打字模式** | 输入完整拼写匹配 | ✅ 有拼写模式 | ✅ 有一定覆盖 |

## 五、UI/UX 风格差异总结

| 维度 | 百词斩 | 墨墨 | 不背单词 | Quizlet | WordWiz |
|------|--------|------|---------|---------|---------|
| **主题** | 清新插画 | 简约卡片 | 全屏沉浸 | 蓝白卡片 | 深色科技感 🌙 |
| **色彩** | 彩色丰富 | 蓝灰系 | 暗色系 | 蓝白系 | 深色暗紫+霓虹 💜 |
| **布局** | 瀑布流 | 列表 | 全屏逐词 | 网格+列表 | 单元分组网格 📐 |
| **移动适配** | ✅ 原生 App | ✅ 原生 App | ✅ 原生 App | ✅ 原生+Web | ⚠️ Web 响应式 |
| **交互反馈** | 精美动画 | 流畅过渡 | 沉浸过渡 | 标准 | 基础淡入淡出 |

> **结论**：WordWiz 的深色科技感 UI 在一众 App 中独树一帜，但交互动效和复杂程度相对基础。

## 六、推荐优先实现的前 5 个功能

基于"投入产出比"分析，建议优先实现：

1. **⭐ 单词发音（TTS）** — 实现最简单（Web Speech API 几行代码），但大幅提升学习体验
2. **⭐ 闪卡翻卡模式** — 新增一种学习模式成本低，带来完全不同的交互感受
3. **⭐ SM-2 间隔算法** — 核心复习算法的优化，直接提升学习效果
4. **⭐ 例句展示** — 配合发音，让单词学习有上下文语境
5. **⭐ 连续学习天数（Streak）** — 游戏化激励，提升用户粘性
