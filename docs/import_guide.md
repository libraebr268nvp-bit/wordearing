# WordWiz 词库导入指南

> 支持通过 CSV / JSON 格式导入雅思、托福、考研、自定义等任何词库。

---

## 一、快速开始

1. **进入设置页** → 点击「数据管理」下的 **「下载模板 CSV」** 按钮，获得一个含表头的模板文件
2. 用 Excel / WPS / VS Code 打开模板，按列填充单词数据
3. 回到设置页，点击 **「选择文件导入」**，选中填好的 CSV 文件
4. 按提示选择目标词书（或自动创建新词书）
5. 导入完成！去首页开始学习

---

## 二、CSV 格式说明

### 文件要求
- **编码：UTF-8**（Excel 另存为时可选择「CSV UTF-8」）
- **表头：第一行为列名（不区分大小写）**
- **分隔符：逗号 `,`**
- **引号：单元格内含逗号时，用双引号括起来**

### 列定义

| 列名 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `word` | ✅ 是 | — | 英文单词（唯一标识，用于去重） |
| `definition` | ✅ 是 | — | 中文释义（可含逗号，用引号括起） |
| `category` | ❌ 否 | `"其他"` | 分类标签（如：雅思、托福、考研、四级、六级等） |
| `unit` | ❌ 否 | `1` | 单元编号，相同编号的单词归为一个单元 |
| `book_source` | ❌ 否 | 文件名 | 词书来源名称。系统会自动创建同名词书，相同来源的单词归入同一词书 |

### 完整示例

```csv
word,definition,category,unit,book_source
abandon,v. 放弃；遗弃,雅思,1,雅思核心词汇
ability,n. 能力；才能,雅思,1,雅思核心词汇
absorb,v. 吸收；吸引,雅思,1,雅思核心词汇
accelerate,v. 加速；促进,雅思,2,雅思核心词汇
accommodate,v. 容纳；向…提供住处,雅思,2,雅思核心词汇
```

也可省略非必填列：

```csv
word,definition
apple,n. 苹果
book,n. 书 v. 预订
cat,n. 猫
```

### 多词书示例（雅思 + 托福）

```csv
word,definition,category,unit,book_source
abandon,v. 放弃；遗弃,雅思,1,雅思核心词汇
zoology,n. 动物学,雅思,10,雅思核心词汇
abase,v. 贬低,托福,1,托福核心词汇
zenith,n. 顶点；顶峰,托福,10,托福核心词汇
```

此时系统会自动创建名为「雅思核心词汇」和「托福核心词汇」两本词书，单词自动归入对应词书。

## 四、JSON 格式导入

除了 CSV，也支持 JSON 格式：

```json
[
  {
    "word": "abandon",
    "definition": "v. 放弃；遗弃",
    "category": "雅思",
    "unit": 1,
    "book_source": "雅思核心词汇",
    "book_id": 1
  },
  {
    "word": "ability",
    "definition": "n. 能力；才能",
    "category": "雅思",
    "unit": 1,
    "book_source": "雅思核心词汇"
  }
]
```

或者包裹在对象中：

```json
{
  "source": "雅思核心词汇",
  "words": [
    { "word": "abandon", "definition": "v. 放弃；遗弃", "category": "雅思", "unit": 1 },
    { "word": "ability", "definition": "n. 能力；才能", "category": "雅思", "unit": 1 }
  ]
}
```

## 五、v5 多归属标签系统（重要）

> 从 v5 版本开始，WordWiz 使用多归属标签系统（`book_ids` 数组），同一单词可以同时属于多本词书。

### 多归属工作原理

```
导入「四级词书」 → 单词 "abandon" 的 book_ids = [四级词书ID]
导入「考研词书」 → 发现 "abandon" 已存在，book_ids 追加为 [四级词书ID, 考研词书ID]
勾选「考研词汇」 → 首页显示所有 book_ids 包含考研词书ID 的单词（包括重叠的 "abandon"）
```

### 核心行为

| 场景 | 行为 |
|------|------|
| 第一次导入某个单词 | 正常添加，`book_ids = [当前词书ID]` |
| 第二次在另一本词书中导入同一单词 | **不覆盖**，追加词书 ID 到 `book_ids` |
| 单词的 `category`（分类） | **保留第一次导入时的值**，不会被覆盖 |
| 单词的 `book_id`（主归属） | **不变**，保留第一次导入时的值 |
| 释义为空时 | 如果已存在单词释义为空，会补充新释义 |
| 释义已存在时 | 不会覆盖已有释义 |

### 示例场景

假设你先导入四级词库（含 `abandon, ability, about` 等），再导入考研词库（也含 `abandon`）：

- `abandon` → 同时属于「四级词库」和「考研词库」，category = '四级'（保留第一次的）
- `ability` → 同上
- 只勾选「考研词汇」→ `abandon`, `ability` 等重叠单词**依然显示**
- 只勾选「四级词汇」→ 四级独有的单词 + 重叠单词都显示

### 关键结论

> **只要某单词被导入过某本词书，勾选该词书就能看到它**，即使它同时属于其他词书。不会出现「勾选考研词汇但重叠单词消失」的问题。

## 六、导入后操作

1. **切换词书筛选** — 首页 → 点击词书按钮可筛选显示特定词书的单词
2. **分类学习** — 首页 → 点击分类按钮（全部/四级/雅思/托福/其他）筛选
3. **查看统计数据** — 设置页顶部显示总单词数、平均熟悉度、收藏数
4. **导出备份** — 设置页 → 导出 JSON/CSV，方便备份或迁移数据

## 七、常见问题

**Q: CSV 文件中的中文显示乱码？**
A: 保存时选用 **UTF-8 编码**。Excel 另存为时选择「CSV UTF-8（逗号分隔）」。
**Q: 导入时提示「重复跳过」，如何覆盖？**
A: 导入时会弹出确认框，选择「确定」即可覆盖已有单词的释义。
**Q: 如何导入多本词书？**
A: 在 CSV 中填写 `book_source` 列，相同书名的单词自动归入同一词书。也可分批导入，每次选择不同目标词书。
**Q: 导入后单词去哪了？**
A: 首页默认显示所有词书的单词。如果首页为空，请检查设置页的词书管理——确认词书已勾选（绿色开关）。
**Q: 一列最多能导入多少个单词？**
A: 无上限。IndexedDB 浏览器的存储限制通常在 50MB 以上，足以容纳数万单词。
