# 后续改进方向

## 已实现的改进

### ✅ v5 多归属标签系统
- 单词通过 `book_ids` 数组支持多词书归属
- 导入去重不再丢失重叠单词的多个书签归属
- 首页词书筛选基于 `book_ids` 精准过滤
- 详见 `docs/import_guide.md` 第五节

### ✅ 挑战模式修复
- 熟练度联动：答对+1 答错-1，上限5下限0
- 错题自动收集到 `wrong_words` 设置
- 7 天冷却避免重复挑战
- 空释义/无定义单词过滤
- 首页搜索定位精确到具体单词项
- 所有排序模式下搜索都能正常工作

### ✅ 提醒系统修复
- Web Notification API 正常请求权限
- 设置页可配置每日提醒时间
- 启动时启动 `startReminderChecker` 定时检查
- 桌面通知 + 页面 Toast + 提示音三重提醒

### ✅ 文档同步
- `favorites_analysis.md`：重写为基于 v6 架构的全链路分析
- `project_overview.md`：补齐 Git 记录、AppState、全局变量、book_ids
- `import_guide.md`：新增 v5 多归属章节，回答「重叠单词会不会丢失」「分类会不会变」

## 计划中的改进

### 🏗️ 更多挑战题型
- 目前 3 种题型（四选一、汉→英、英→汉），可增加听写模式、拼写模式、配对模式等
- 支持自定义挑战参数（题数、时间、难度范围）

### 📊 学习统计增强
- 增加月度/年度统计报告
- 学习打卡日历（GitHub 风格热力图）
- 遗忘曲线预测（基于艾宾浩斯遗忘曲线）

### 🔄 数据同步
- 可选云端同步（基于 IndexedDB 导出 + 服务器存储）
- 多设备学习进度合并（冲突解决策略）

### 🎯 个性化学习
- 基于熟练度的自适应学习（自动推荐低熟悉度单词）
- 每日推荐学习量（基于历史学习速度）
- 自定义学习计划（每日新词数 + 复习数）

### 🌐 多语言支持
- 界面国际化（中/英切换）
- 支持其他语种词库（日语、法语、德语等）

### 🔍 搜索增强
- 通配符搜索（`ab*` 匹配所有以 ab 开头的单词）
- 正则表达式搜索
- 搜索历史记录

### 🎮 游戏化增强
- 排行榜（局域网内用户排名）
- 连续学习天数成就
- 更多成就类型（如：收集所有分类的单词、挑战满分等）

### 🧪 技术优化
- 单元测试覆盖（当前为 0）
- 性能优化（大数据量下的虚拟滚动）
- PWA 支持（离线访问 + 安装到桌面）
- 数据导出增加加密选项
- 自动备份到本地文件
