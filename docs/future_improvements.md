# WordWiz 后续改进方案构思 (v2.0)

基于当前代码架构和已解决问题，以下是未来的改进方向：

---

## 一、核心功能增强

### 1. 多词书归属标签系统 ★★★★
- **现状**：单词只属于首次导入时的词书，勾选特定词书时看不到重叠的单词
- **改进方案**：给单词增加 `book_ids: []` 多归属数组字段，同一单词可标记属于多本词书
- **效果**：勾选「考研词汇」时，即使单词先从四级导入，也能显示在考研词书中
- **难点**：涉及数据库结构变更、已有数据迁移、查询逻辑重写

### 2. 复习计划（Spaced Repetition）★★★★★
- **现状**：挑战模式有7天冷却，但无系统性复习计划
- **改进方案**：引入类 Anki 的间隔重复算法（SM-2）
  - 每次挑战后，根据答对/答错计算下次复习日期
  - 首页增加「待复习」筛选模式
  - 到期的单词在首页置顶显示
- **效果**：科学复习，最大化记忆效率

### 3. 单词联想 / 例句系统 ★★★
- **现状**：单词只有释义，没有例句和联想
- **改进方案**：
  - 导入时支持例句列（example_sentence）
  - 收藏或查看单词时展示例句
  - 后期可接入离线词典数据源

### 4. 学习进度统计分析 ★★★★
- **现状**：只有基础统计（总词数、学习天数等）
- **改进方案**：
  - 折线图展示每日学习量趋势（使用 Canvas）
  - 饼图展示熟悉度分布
  - 词书掌握度百分比
  - 历史挑战成绩趋势

## 二、用户体验优化

### 5. 键盘快捷键 ★★★
- 首页按 `f` 聚焦搜索框
- 按 `Enter` 直接进入第一个搜索结果
- 挑战模式按 `1/2/3/4` 选择选项
- 按 `Space` 暂停/继续挑战计时

### 6. 拖拽排序 / 批量操作 ★★★★
- **现状**：单词操作只能一个个点
- **改进**：
  - 长按可多选单词
  - 批量收藏 / 批量删除 / 批量修改熟悉度
  - 拖拽调整单元顺序

### 7. 暗黑模式 ★★★
- **现状**：只有浅色主题
- **改进**：增加暗黑模式切换，使用 CSS 变量 + prefers-color-scheme 自动检测

### 8. 响应式布局增强 ★★★★
- **现状**：首页词书按钮可折叠，但挑战/错题页在小屏下仍有问题
- **改进**：
  - 使用 CSS Grid / Flexbox 全面优化移动端布局
  - 触摸事件优化（滑动切换标签页）
  - 移动端底部导航栏

---

## 三、数据与导入

### 9. 自动网络词库下载 ★★★
- **现状**：手动找 CSV/JSON 文件导入，对新手不友好
- **改进**：内置一些常用词库作为模板下载选项（四六级、考研、雅思托福等）
  - 需要将词库文件打包到项目中
  - 或首次启动时从 GitHub 仓库下载

### 10. 数据云同步（可选）★★
- 使用 WebDAV 或第三方存储服务备份/恢复数据
- 支持多设备间同步学习进度

### 11. 导入预览与冲突检测 ★★★★
- **现状**：导入时只显示 success/skipped 数字
- **改进**：
  - 导入前预览：显示将要导入的单词列表（样本展示）
  - 冲突检测：高亮显示已存在的单词，让用户选择保留哪个词书的分类

---

## 四、挑战模式增强

### 12. 更多挑战题型 ★★★
- 听音辨词（需要 TTS 支持）
- 完形填空（展示带空格的例句）
- 词义配对（多词多义连线匹配）

### 13. 挑战排行榜（本地）★★
- 记录每次挑战得分，展示本地历史记录
- 统计最佳成绩、平均正确率
- 成就感激励学习

### 14. 每日挑战任务 ★★★★
- **现状**：挑战没有留痕机制，用户可能忘记学习
- **改进**：
  - 每日签到奖励（连续签到天数 + 额外成就）
  - 每日挑战任务（今日目标：答对50题、复习20个旧词等）
  - 任务完成度进度条

---

## 五、技术架构升级

### 15. 使用 Service Worker 离线 PWA ★★★★
- **现状**：必须保持标签页打开才能提醒
- **改进**：
  - 注册 Service Worker，实现真正的后台通知推送
  - 配置 manifest.json，支持添加到手机主屏幕
  - 离线缓存资源，即使无网络也能打开应用

### 16. 本地数据加密备份 ★★★
- 导出时支持加密（密码保护）
- 导入时需输入密码解密
- 保护隐私数据安全

### 17. 性能优化 ★★★
- 单词数量达到 10000+ 时，首页分页加载（虚拟滚动）
- 搜索使用防抖 + 索引缓存
- 挑战模式预加载题库
