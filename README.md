# WordWiz 单词学习助手

一个基于浏览器的单词学习应用，支持英汉互译背词、挑战模式、闪卡复习等功能。

## 快速开始

```bash
# 启动本地服务器
python server.py

# 或
node server.js
```

浏览器打开 `http://localhost:3000` 即可使用。

## 功能概览

### 📚 首页词库
- 单词列表浏览，支持分类筛选（全部/已掌握/待复习/回收站）
- 排序方式：默认/熟悉度高低/字母序/随机打乱
- 三种视图模式：列表/闪卡/沉浸式阅读
- 单词详情卡片：显示释义、词性、例句、熟悉度
- 编辑/删除/移入回收站

### ⚡ 挑战模式
- **4 种答题模式**：
  - 📋 看英文选中文 — 显示单词，四选一中文释义
  - 📋 看中文选英文 — 显示释义，四选一英文单词
  - ✍️ 逐格拼写 — 逐个字母输入拼写（自动跳格+退格返回，连字符自动填入）
  - 🃏 配对游戏 — 翻牌匹配单词与释义
- **拼写提示**：每题 2 次提示，逐格填充字母
- **高级设置**：题数（10/20/50/100/自定义）、范围（激活词书/全部/按分类/错题集/今日待复习）、难度（简单/普通/困难）
- **附加选项**：生命值模式（1/3/5/10 条命可调）、限时模式（5/10/15/20/30 秒可调）
- **7 天冷却**：已挑战的单词 7 天内不会重复出现
- **答题动画**：绿色闪光 / 红框震动 / 爱心裂开 / 连击弹窗 / 心碎飘出
- 错题收集（200 条上限）、挑战历史记录

### ❤️ 收藏夹
- 收藏单词管理
- 分类筛选、多排序方式
- 熟悉度跟踪

### ⌨️ 打字模式
- 看中文打英文
- 实时统计正确率

### 📊 统计
- 学习趋势图
- 学习热力图
- 词库完成度统计

### ⚙️ 设置
- 词书管理（激活/停用）
- 主题切换（深色/浅色）
- 导入/导出单词数据

## 技术栈

- **前端**：原生 JavaScript (ES6+)，无框架依赖
- **样式**：CSS 变量 + Flexbox/Grid，支持深色/浅色主题
- **存储**：IndexedDB（通过 `idb` 库封装）
- **路由**：基于 Hash 的前端路由
- **服务器**：Python/Node.js 静态文件服务
- **PWA**：支持添加至主屏幕

## 词库来源

内置词库文件（JSON 格式）：
- `words_zk.json` — 中考词汇
- `words_gk.json` — 高考词汇
- `words_cet4.json` — 大学四级
- `words_cet6.json` — 大学六级
- `words_ky.json` — 考研词汇
- `words_ielts.json` — 雅思词汇
- `words_toefl.json` — 托福词汇
- `words_gre.json` — GRE 词汇

## 开发说明

本项目为纯前端应用，所有数据存储在浏览器的 IndexedDB 中。启动本地服务器后即可使用，无需后端数据库。
